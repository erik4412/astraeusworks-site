# Astraeus Works website

Static product website for [astraeusworks.shop](https://astraeusworks.shop), designed for GitHub Pages.

## Local preview

Open `index.html` directly, or serve this directory with any static web server.

## GitHub Pages

Publish from the `main` branch and repository root. The included `CNAME` file configures `astraeusworks.shop` as the custom domain.

The site deliberately describes Astraeus Terrain Studio and Worldforger as products in development. Update product status and purchase links only when those claims become true.
